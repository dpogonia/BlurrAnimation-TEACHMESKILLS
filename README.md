# Blurr

Один экран с подписью, размытием и алертом. Урок 14 школы TeachMeSkills.

## Что умеет приложение

На экране подпись Apple и три кнопки. Первая сдвигает подпись вниз. Вторая на две секунды показывает размытие поверх картинки. Третья открывает меню с действиями OK, Cancel и destructive.

## Курс

TeachMeSkills, урок 14, июль 2023. Проект сделан между первым приложением школы и началом курса Angela Yu.

## Стек

UIKit, Storyboard, UIVisualEffect.

## Запуск

```bash
git clone https://github.com/dpogonia/BlurrAnimation-TeachMeSkills.git
cd BlurrAnimation-TeachMeSkills
open Lesson14.xcodeproj
```

Запустите схему **Lesson14** на симуляторе iPhone.
