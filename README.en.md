# Blurr

One screen with a label, a blur, and an alert. Lesson 14 from TeachMeSkills.

## What it does

The screen shows an Apple label and three buttons. The first moves the label down. The second puts a blur over the picture for two seconds. The third opens an action sheet with OK, Cancel, and a destructive action.

## Course

TeachMeSkills, lesson 14, July 2023. The project sits between the school's first app and the start of the Angela Yu course.

## Stack

UIKit, Storyboard, UIVisualEffect.

## Run

```bash
git clone https://github.com/dpogonia/BlurrAnimation-TeachMeSkills.git
cd BlurrAnimation-TeachMeSkills
open Lesson14.xcodeproj
```

Run the **Lesson14** scheme on an iPhone simulator.
